# dotfiles

Personal configuration files for my development workflow. I'm using <https://www.chezmoi.io> to help manage my dotfiles across machines (including devcontainers). The setup script will download and install Chezmoi and clone my dotfiles. It will also set zsh as the default shell if available, create the .zsh directory if it not already exist, and install <https://github.com/sindresorhus/pure> a minimal zsh prompt.
